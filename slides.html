02 • WHAT DEPLOYMENT MEANS

What does “deployment” actually mean?

Code

your laptop

➔

Build

bundle or image

➔

Test

automated checks

➔

Artifact

versioned package

➔

Staging

rehearsal

➔

Production

real users

Deployment = one tested version, running where real users can reach it.

Your laptop is not production. Something has to move the code there safely, every single time.

05 • CONTINUOUS DELIVERY VS DEPLOYMENT

Who presses Dispatch?

CONTINUOUS DELIVERY

Packed and ready. The manager taps Dispatch.

Build ➔ Test ➔ Staging ➔ 👤 Human approves ➔ Production
Keep a human gate:

Banking • Healthcare • App stores

CONTINUOUS DEPLOYMENT

A rider is auto-assigned the moment it’s packed.

Build ➔ Test ➔ Staging ➔ ⚡ Automatic ➔ Production
Full automation, once earned:

Web apps • SaaS • Internal tools

Same pipeline. One difference: who approves the step to production.

06 • WHY IT MATTERS TODAY

When shipping goes wrong

JULY 2024 • CROWDSTRIKE

Global Windows Outage

One faulty update went to every customer at once. About 8.5 million Windows machines crashed, grounding flights worldwide.

Safer: A Canary Rollout
1% 10% 50% 100%
Lesson: Roll out gradually
MARCH 2025 • TJ-ACTIONS

Pipeline Supply Chain Attack

A GitHub Action used by 23,000+ repos was hijacked to quietly print secrets into build logs (CVE-2025-30066).

Safer: Secure the Pipeline Itself
  • ✔ Platform Secret Store
  • ✔ Least Privilege Tokens
  • ✔ Pin Actions to a Commit SHA
Lesson: Guard the keys to production
